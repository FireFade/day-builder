# Day Builder v0.6 — регресійне тестування

Підготуй копію даних і тестуй v0.6 в окремій папці. Для Google Calendar використовуй уже підключений акаунт та не змінюй зовнішні зустрічі з Day Builder. Усі операції над тижнем підтверджуються вручну.

| ID | Дії | Очікуваний результат |
|---|---|---|
| W01 | Тиждень → вибери будь-яку дату, відкрий «Тиждень» | Відображаються понеділок–неділя з активностями, харчуванням, зустрічами |
| W02 | Зніми галочку з двох днів → підтверди тиждень | Змінені лише вибрані дні; два невибрані залишилися попередніми |
| W03 | Після завантаження тижня зміни зустріч Google → синхронізуй → підтверди стару пропозицію | HTTP 409, жоден вибраний день не повинен частково зберегтися |
| W04 | Познач завдання виконаним, закріпи інший блок → сплануй тиждень | Виконане й закріплене зберігаються за правилами перепланування |
| W05 | Створи активність «Разово» на 12.10 → переглянь тиждень | Її немає 11.10 та 13.10; є лише 12.10 |
| A01 | Аналітика → 7 / 30 / 90 днів | Перераховуються відомості лише зі збережених днів; немає вигаданої статистики |
| A02 | Познач справу виконаною, пропусти іншу, онови аналітику | Лічильники done/skipped зміняться відповідно |
| F01 | Фокус → 5 хв, введи назву, старт, пауза, продовження | Час зупиняється на паузі, продовжує після неї |
| F02 | Фокус → після щонайменше 1 хв натисни «Завершити» | Запис у журналі, хвилини враховані в аналітиці |
| F03 | Фокус → онови сторінку під час сесії | Після повернення таймер відновлюється з локального стану; повторного запису немає |
| F04 | Видали фокус-сесію | Зникає з журналу та статистики |
| R01 | Мій день → настрій, енергія, нотатка → зберегти → перезавантажити | Дані збереглися для правильної дати; можна редагувати |
| N01 | Налаштування → інтервал нагадувань 5/15/30 → зберегти | Значення зберігається в цьому браузері; нагадування працюють при відкритій вкладці |
| UI01 | 390, 1100, 1440 px, Windows scaling 125–150%, Browser Zoom 100–200% | Форма прокручується, нижні кнопки доступні, обидві галочки лишаються в квадратах |
| G01 | Підключений Google → зміни час тестової зустрічі → синхронізуй → онови день | Немає дублікатів; план позначений застарілим; новий план не накладається на зустріч |
| S01 | Перезапусти сервер після створення тижня, фокус-записів і нотаток | Усі збережені дані залишилися; зашифровані OAuth-токени не втрачено |

## Обмеження першого релізу

- Фонові push-повідомлення після закриття вкладки не реалізовані. Налаштовувані повідомлення потребують дозволу браузера й відкритої сторінки.
- Інтерфейс React із папки `frontend/` поки не має повного функціонального паритету. Використовуй `http://localhost:8000/`.
- Фокус-таймер зберігає цілу кількість завершених хвилин. Він не переводить статус справи автоматично у «Виконано».
- Після зміни правил повторення раніше збережені дні потребують перебудови, але вихідні Google-події не редагуються.
